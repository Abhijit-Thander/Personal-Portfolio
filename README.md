## ✨ Overview

This is my personal portfolio website — designed to be clean, fast, and smooth to navigate. It highlights my projects, technical skills, and the story behind my journey as a developer, wrapped in a buttery-smooth scrolling experience.

## 🚀 Features

- 🎨 **Modern, minimal UI** — designed with a focus on clarity and visual hierarchy
- 🧈 **Buttery-smooth scrolling** powered by **Lenis**
- 📱 **Fully responsive** — looks great on mobile, tablet, and desktop
- ⚡ **Blazing fast** — built with **Vite** for instant load times
- 🧩 **Component-based architecture** using React
- 🌗 Clean, utility-first styling with **Tailwind CSS**

## 🛠️ Built With

<div align="center">

| Technology       | Purpose                  |
| ---------------- | ------------------------ |
| **React**        | Component-based UI       |
| **Tailwind CSS** | Utility-first styling    |

## 📂 Getting Started

Clone the repo and run it locally:

```bash
git clone https://github.com/Abhijit-Thander/avi-portfolio.git
cd avi-portfolio
npm install
npm run dev
```

Then open **http://localhost:5173** in your browser.

## 📁 Project Structure

```
portfolio/
├── src/
│   ├── pages/          # Page components (Home, Projects, Skills, etc.)
│   ├── components/     # Reusable UI components
│   ├── assets/         # Images, icons, fonts
│   └── App.jsx
├── public/
├── index.html
└── vite.config.js
```
